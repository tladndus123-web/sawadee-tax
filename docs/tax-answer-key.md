# 세금 정답 예시 (Tax answer key)

손으로 계산한 정답이에요. `lib/tax-golden.test.ts`가 배포 때마다 코드가 같은 답을 내는지 확인해요.
세무사가 다르다고 하면 이 표와 테스트의 답을 함께 고쳐요. AI가 규칙을 정하지 않아요.

마지막 확인: 2026-11-18, 21개 모두 코드와 일치. 세무사 확인: 아직.

## 부가세 VAT 7% (ภ.พ.30)
| | 예시 | 정답 |
|---|---|---|
| V1 | 세금계산서 1,000 + VAT 70 (우리 회사 앞) | 매입세액 70 공제 |
| V2 | 매출 10,700 (VAT 포함) | 공급가 10,000 · 매출세액 700 |
| V3 | 매출세액 7,000, 매입세액 3,500 | 낼 부가세 3,500 |
| V4 | 매출세액 700, 매입세액 3,500 | 낼 것 0 · 더 낸 2,800 (환급 또는 이월) |
| V5 | 간이 영수증 / 우리 회사 앞이 아님 / 사본 | 공제 안 됨 |
| V6 | 2026-03 발행 세금계산서 | 2026-09 신고까지 공제, 2026-10부터 불가 (6개월) |
