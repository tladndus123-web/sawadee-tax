# 태국 세금계산서 요건 대조표 (2026-09-25)

앱의 **정리된 양식**과 **자동 확인**이 태국 국세청이 정한 세금계산서 기재 사항을 제대로 다루는지 대조한 결과예요.
법 해석이 아니라 "필수 항목을 읽고 · 보여 주고 · 확인하는가"를 본 거예요. 최종 판단은 회계사와 확인해 주세요.

## 고칠 것 (제안)

1. **판매자 본사/지점 읽기 · 표시 (8b, 꼭 필요):** AI가 읽는 항목에 `seller.branch`("สำนักงานใหญ่" 또는 "สาขาที่ 00001")를 추가하고, 양식의 고정 문구 대신 읽은 값을 보여 줘요. 없으면 "확인 필요".
2. **필수 기재 사항 검사 1개 추가:** 정식 세금계산서일 때 1 · 2 · 3 · 4 · 8b · 8c가 모두 있는지 한 줄로 알려 주고, 빠진 칸 이름을 표시해요.
3. **공제 가능 판정에 반영:** 2번이 실패하면 `claimable = false`.
4. **공제 기한 경고:** 발행일부터 3년이 지나면 경고.
